# الحمراء — قصيدة من حجر | Alhambra: A Poem in Stone

فيلم موشن جرافيك وثائقي بأسلوب **VOX** (كولاج ورقي — Documentary Archive Collage / LOCK A)،
مُنتَج ومُصيَّر بالكامل بالكود: كل إطار دالة زمن `window.seek(t)`، محرّك كاميرا افتراضية
(دفع/تحريك/زوم + بارالاكس حسب عمق الطبقة)، إضاءة دافئة متحركة مع غبار ضوئي،
تبديل تركيز (Rack Focus)، وإيقاع Stop-Motion داخل تايملاين سلس.

## الفيلم النهائي
- **المدة:** 4:25.41 · **المواصفات:** 1280×720 · **32fps** · H.264 + AAC 48kHz · ‏-16 LUFS
- **التعليق الصوتي:** الملف الأصلي، والمشاهد متزامنة مع 79 مقطعًا صوتيًا مقاسًا فعليًا
- **المؤثرات:** 60+ مؤثرًا واقعيًا مولّدًا برمجيًا (ورق، حجر، قلم، ماء، عود، مفتاح معدني، أختام)
- ⬇️ التحميل/المشاهدة: صفحة **Releases** (v1.0.0) أو `renders/alhambra_full_film.mp4`

## البنية
| المسار | الوصف |
|---|---|
| `index.html` | الفيلم كاملًا: 13 مشهدًا (S1–S13) بدوال زمن نقية ونوابض فيزيائية |
| `render.mjs` | التصيير عبر Chromium + FFmpeg (`--fps 32 --start --dur` للأجزاء) |
| `assets/plates/` | 3 لوحات سينمائية كاملة الإطار |
| `assets/sheets/` | 10 لوحات أصول مولّدة (عمودية) |
| `assets/el/` | 72 قصاصة مقصوصة تلقائيًا من اللوحات |
| `assets/cut/` | قصاصات الحزمة الأولى (قصر/جدار/غرناطة/مخطوطة/حجر) |
| `renders/` | أجزاء التصيير الخمسة + الفيلم النهائي |
| `docs/` | مخطط اللقطات والفصول |

إعادة التصيير: `node render.mjs --fps 32 --dur 265.44 --out final.mp4`

بُني بمهارة AI Film Studio (توجيه E1 + القفل البصري LOCK A) ومحرك motion-reel البرمجي.
